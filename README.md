# Sistema de Gerenciamento de Agendas

Sistema completo de gerenciamento de agendas com PWA, integração com Google Sheets e Google Apps Script.

## 📋 Características

- ✅ PWA completo com Service Worker
- ✅ Interface estilo Apple iOS 26
- ✅ Glassmorphism e animações suaves
- ✅ Dark/Light Mode automático
- ✅ Dashboard com gráficos interativos
- ✅ Sistema de autenticação com roles
- ✅ CRUD completo de agendas
- ✅ Sistema de notificações
- ✅ Solicitações de alteração
- ✅ Integração com Google Maps
- ✅ Responsivo (Desktop, Tablet, Mobile)
- ✅ Offline mode

## 🚀 Tecnologias

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Backend**: Google Apps Script
- **Banco de Dados**: Google Sheets
- **Hospedagem**: Vercel
- **Versionamento**: GitHub
